将Qt for Python带到Android
2023 年 4 月 19 日 作者 Shyamnath Premnadh |评论

如今，将 Python 应用程序部署到 Android 是 Python 社区的一大话题，也是开发第一个 GUI 应用程序的人们经常问的问题。已经有几个Python框架提供了将应用程序部署到Android设备的能力，而Qt for Android已经存在了十年。 借助QML和Qt Quick，可以使用Qt开发原生Android应用程序。现在是我们弥合差距并将 PySide 应用程序引入 Android 的时候了。 

在新的 6.5 版本中，我们为您提供了一个新的 CLI 工具 pyside6-android-deploy，它提供了一个简单的界面来部署 PySide6 应用程序🎉。 

技术细节

目前，此工具仅在基于Linux的环境中可用，并且仅支持Qt模块的子集（请参阅注意事项）。 

该工具使用 python-for-android 项目的自定义分支，带有自定义 Qt 引导程序以及 PySide6 和 shiboken6 的配方。使用 python-for-android 而不是 androiddeployqt 的原因是 python-for-android 已经提供了一种打包 Python 解释器的方法，默认情况下，Python 解释器不会预装在 Android 平台上。它还可以很容易地扩展以包括新的Python包，甚至是那些具有C / C++后端的包。python-for-android 已经支持许多流行的 Python 包，如 numpy、pandas 等。 

整个部署过程分为 3 步，每个 Android 平台只需执行前两个步骤。前两个步骤是设置和交叉编译 pyside6-android-deploy 工作所需的 Qt for Python 轮子。 

将 PySide 应用程序部署到 Android 的步骤

如上所述，对于特定的 Android 架构，只需执行一次步骤 1 和 2。您部署的每个 PySide6 应用程序都将使用相同的 Qt for Python 轮子。 

步骤 1：设置先决条件

PySide6 的 Android 依赖项与 Qt for Android 的依赖项相同。此步骤涉及下载 JDK、Android NDK 和 Android SDK。如果您已经下载并设置了它们，则可以跳过此步骤。PySide6 版本 6.5 的推荐 NDK 版本为 r25。您可以使用Qt Creator安装所有依赖项，也可以手动安装依赖项，如下所示。  

1. 安装 JDK 11 或更高版本。请参阅此处的说明。
2. 下载适用于 Linux 的最新版本的“仅限 Android 命令行工具”。这将下载一个 .zip 文件。
3.您可以使用以下脚本将 Android SDK 和 NDK（r25c） 下载并安装到当前工作目录中。

#!/bin/bash 
shopt -s extglob 
if [ -z "$1" ] 
  then 
    echo "Supply path to  commandlinetools-linux-*_latest.zip" 
    exit 1 
fi 
android_sdk=$(pwd)/android_sdk 
mkdir -p $android_sdk 
unzip $1 -d $android_sdk 
latest=$android_sdk/cmdline-tools/latest 
mkdir -p $latest 
mv $android_sdk/cmdline-tools/!(latest) $latest 
$latest/bin/sdkmanager "ndk;25.2.9519653" "build-tools;33.0.2" "platforms;android-31" "platform-tools" 
cp -avr $android_sdk/cmdline-tools/latest $android_sdk/tools
只需通过授予脚本执行权限 （chmod +x） 并将下载的 .zip 文件的路径作为 cli 参数传递来运行脚本。

4. 将 Android SDK 和 NDK 路径添加到以下环境变量中： 

export ANDROID_SDK_ROOT=“/android_sdk” 
export ANDROID_NDK_ROOT=“/android_sdk/ndk/25.2.9519653” 
第 2 步：交叉编译适用于 Android 的 Qt for Python 轮

Python-for-android 要求在部署过程中交叉编译 shiboken6 和 PySide6，以生成与特定 Android 平台兼容的 Qt for Python 二进制文件。每次为每个应用程序交叉编译Qt for Python可能是一项繁琐而耗时的任务😫。因此，最好使用一次交叉编译来为 Android 平台创建 Qt for Python 轮子，它可以在您部署的每个应用程序中重用。我们通过Qt for Python源代码存储库中提供的Python脚本使您更容易创建这些轮子。

确保安装所有项目要求，包括“获取源代码”，然后安装交叉编译要求，如下所示： 

pip install –r tools/cross_compile_android/requirements.txt 
并运行以下脚本：  

python tools/cross_compile_android/main.py --plat-name=aarch64 --ndk-path=$ANDROID_NDK_ROOT --qt-install-path=/opt/Qt/6.5.0 --sdk-path=$ANDROID_SDK_ROOT
在上面的命令中，--plat-name 指的是 aarch64、armv7a、i686 x86_64之一，具体取决于目标架构。--qt-install-path 是指安装 Qt 6.5.0 或更高版本的路径。使用 --help 查看所有其他可用选项。   

成功完成此命令后，您将在“pyside-setup/dist”文件夹中拥有Qt for Python轮。 

Note: We recommend using venv or virtuanenv
步骤 3：部署应用程序 - pyside6-android-deploy

在本教程中，我们采用一个简单的 QtQuick 示例 Scene Graph Painted Item 示例。您可以直接从链接下载此示例。pyside6-android-deploy 工具的一个主要要求是主 Python 入口点文件应命名为 main.py。将 painteditem.py 的名称更改为 main.py，并在 painteditem.pyproject 中进行相应调整。将主 Python 入口点命名为 main.py 的要求来自 python-for-android。拥有 .pyproject 文件并不是一个严格的要求，但它使 pyside6-android-deploy 能够更轻松地找到与项目关联的文件，并且不包含任何不必要的文件。 

运行以下命令： 

pyside6-android-deploy --wheel-pyside=pyside-setup/dist/PySide6-6.5.0a1-6.5.0-cp37-abi3-android_aarch64.whl --wheel-shiboken=pyside-setup/dist/shiboken6-6.5.0a1-6.5.0-cp37-abi3-android_aarch64.whl --name=painteditem  
在上面的命令中，--name 引用应用程序的名称，如您的 Android 设备中所示。使用 --help 查看其他可用选项。 

在此命令结束时，您将在应用程序目录中创建一个 .apk 文件，您可以将其安装在基于 aarch64 的 Android 设备上。 欢呼，您已经成功地将Qt for Python应用程序带到了Android🎉上。

考虑🤔

1. 目前，“pyside6-android-deploy”工具仅适用于 Linux。
此限制来自我们的交叉编译基础架构，我们正在积极寻求改进，并允许 macOS 和 Windows 用户也部署 Android 应用程序。

2. 支持的Qt模块：QtCore、QtGui、QtWidgets、QtNetwork、QtOpenGL、QtQml、QtQuick、QtQuickControls2.

3. 应用程序的主要 Python 入口点应命名为 main.py
此要求来自 python-for-android。
