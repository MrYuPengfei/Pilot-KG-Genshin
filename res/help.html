一、程序是怎么工作的（窗口与托盘）

本程序启动后只有一个窗口：系统托盘里的图标。桌面上的伙伴是它的一部分， 任务栏里不会出现它——这是有意设计的，桌面挂件不该在任务栏占位置。 所有功能入口都在托盘图标右键菜单里：

菜单项作用
人物列出资源库里的全部人物，点击即切换（切换后会按当前时段问好）
音乐地区背景音乐、人物语音开关；当前项带「～」表示正在播放
管理面板打开管理面板（见下一节）
显示伙伴被隐藏后用它唤回
退出真正结束程序并保存设置

桌面上的伙伴可以拖动、右键打开快捷菜单（了解 / 闲聊 / 隐藏 / 退出）。 「隐藏」是把伙伴设为透明，程序仍在运行，用托盘菜单的「显示」唤回。

快捷键（桌面伙伴获得焦点时）： Ctrl + ↑ / Ctrl + ↓ 放大缩小， Ctrl + Q 退出程序。

单实例：本程序同时只允许运行一个实例，重复双击安装包或 exe 不会再出现第二个托盘图标（否则两个实例会互相覆盖设置）。

二、管理面板：六个标签页

管理面板是一个独立的主窗口（任务栏有它自己的图标，可最小化、最大化、还原）， 六个标签页分别承担人物、音乐、素材、图谱、窗口控制与帮助。 面板不用菜单栏——所有功能都挂在标签页上，再加一层菜单只会让 「换页」与「做事」分散在两处。

标签页能做什么
人物管理 列出全部人物（含导入的），选中后显示首帧预览与帧数 / 语音数； 可按人物调整帧间隔（20~1000ms）与缩放比例（0.1~3.0）、「设为当前伙伴」、 「删除此人物」。设为当前伙伴会立即切换桌面上的挂件。
音乐管理 选择地区播放 / 停止背景音乐、开关人物语音、一键关闭所有声音； 与托盘「音乐」菜单的「～」选中状态双向同步。
素材管理 查看资源统计（人物 / 地区 / 帧 / 语音数量、数据库大小）； 导入 zip 素材包或素材目录；导出素材（全部或仅当前人物，目录或 zip， 结果可再导入）；导出与导入配置 JSON；导入与导出图谱 CSV； 重新载入图谱。
知识图谱 搜索实体后展示以该实体为中心的自我中心网；单击节点看属性与关系清单， 双击节点以它为中心重新展开，滚轮缩放、拖拽平移。 右侧可新增 / 编辑 / 删除实体与关系。首次打开该页时才加载图谱数据。
窗口与状态 窗口操作：最小化、最大化 / 还原、全屏 / 退出全屏、隐藏面板， 以及「显示桌面上的伙伴」勾选项（与托盘菜单的显隐操作双向同步）。 当前状态：窗口状态、当前伙伴、资源库与版本号。 快捷键 Ctrl+1 ~ Ctrl+6 可直接切到对应标签页。
帮助文档本页：使用说明、数据备份、常见问题、版本记录与许可。

关于「关闭面板」：点面板的关闭按钮（或 Alt+F4）只是把它隐藏， 程序和伙伴都还在运行，托盘图标也还在——随时可以从托盘「管理面板」 原样唤回，已填好的表单不会丢。要彻底结束程序请用托盘菜单的「退出」。

关于全屏：全屏后标签页与标题栏控件都可能被盖住，按 Esc 即可退出； 按钮文字也会自动在「全屏 / 退出全屏」之间切换。

关于「显示桌面上的伙伴」：这是状态而非动作，所以用勾选框表示。 在托盘隐藏或显示伙伴后，这里的勾选状态会同步更新，反之亦然—— 两处始终一致，不会出现「勾着却看不见」的情况。

三、导入与导出素材

通过「素材」页导入 zip 文件或目录。素材包内部必须沿用如下布局 （png/ 与 music/ 可只提供其一）：

素材包/
  png/<人物>/*.png                人物帧（逐帧 PNG）
  music/<人物>/*.mp3              人物语音
  music/<地区>/background.mp3     地区背景音乐

规则与约定

  • 帧图片：建议统一尺寸、按播放顺序命名（如 0001.png、0002.png…）， 程序按文件名排序播放；单帧人物也能正常显示（静态图）。
  • 语音命名决定自动分类：「早上好 / 中午好 / 晚上好 / 晚安」归入问候 （按当前时段自动播放），「闲聊*」归入闲聊，「想要了解*」归入了解； 其余命名不分类，仅占用语音列表。分类按关键词匹配， 所以「早上好问候菲谢尔.mp3」这类带后缀的文件也能被正确识别。
  • 地区识别规则：music/ 下只要目录内含 background.mp3 即被识别为地区， 因此请勿把 background.mp3 放进人物语音目录。
  • 同名覆盖：重复导入时同名资源会被覆盖更新，不会产生重复记录。
  • 新人物默认值：首次导入的人物按 帧间隔 60ms、缩放 1.0 登记， 可在「人物」页调整并保存。
  • 导入即生效：新人物 / 新地区立即出现在托盘菜单与人物列表里，无需重启。

导出素材（备份与分享）

「素材」页可以把资源库中的素材按上面这套布局还原成目录或 zip。 导出的包能被现有导入器直接并入，因此可用于备份、离线编辑后回导、分享给他人。 可选择范围：

  • 全部素材：所有人物 + 所有地区背景音乐；
  • 仅当前人物：只导出该角色的帧与语音（不含地区背景音乐）。

资源库约 460MB，全量导出需要几十秒，期间界面会短暂无响应， 进度对话框上的「取消」会在当前文件处理完后生效。

删除素材：素材页可删除已导入的人物或地区。 删除只影响资源库中的记录，不会删除你的原始素材文件。

版权提醒：本项目仅供学习交流，请勿导入或分发侵犯第三方版权的素材。

四、知识图谱

图谱数据存放于程序目录下的 kg.db（SQLite），随安装包分发。 它包含三张表：kg_nodes（实体，属性以 JSON 保存）、 kg_edges（有向关系）、kg_meta（库结构版本与来源）。 首次切到知识图谱页时才加载数据（约 1900 个实体、7300+ 关系，耗时不到 1 秒）。

怎么看图谱

  • 在搜索框输入实体名（人物、武器、材料、副本、料理…）后回车或点「定位」， 以该实体为中心画出自我中心网；
  • 单击节点看属性与关系清单；双击节点以它为中心重新展开；
  • 滚轮缩放、拖拽平移；节点颜色代表实体类型（图例见页面底部）。

编辑

  • 编辑实体：可改名、改类型、增删属性。改名或改类型时， 其全部关系的两端会自动跟着迁移，不会出现断链。
  • 删除实体：会连带删除该实体的所有关系，操作前有确认弹窗提示关系条数。
  • 编辑关系：在关系列表中选中一条（→ 出边 / ← 入边）， 可改关系名或更换对端实体；两端可直接输入新名字， 输入不存在的名字会自动按所选类型建为新实体。
  • 关系名：填写 element_is、part_of 等已有键 会显示对应中文（神之眼、属于…）；也可以自填中文或英文，此时按原文显示。

导入 / 导出 CSV

  • 导入：可选 CSV 目录（推荐，label-*.csv + rel-*.csv） 或单个 CSV 文件。单个文件按表头自动识别：含 node1,rel,node2 视为关系表， 含 name 且含 label/type 视为实体表。 模式可选合并（同名实体覆盖属性）或覆盖（先清空现有图谱）。
  • 导出：实体表命名为 label-<类型>.csv， 关系表按真实方向命名为 rel-<源类型>-<目标类型>.csv。 该目录可被「导入」整目录回灌，便于备份、分享与用表格软件编辑。

改动何时落盘

每一次增删改都会立刻写入 kg.db——新增或修改实体、编辑或删除关系、 导入 CSV，操作完成的那一刻就已经存好了，不需要再点保存、也不会因关窗口而丢失。 中途若弹出错误（例如「同名实体已存在」「关系的两端不能是同一实体」）， 那一步不会写库，之前的改动也不受影响。

同样地，覆盖安装/升级不会覆盖你的 kg.db：安装器只在 kg.db 不存在时才写入出厂图谱，所以升级新版本后你编辑的实体与关系都还在。 反过来说，新版本附带的出厂图谱也不会自动更新到已安装的机器上—— 想要最新出厂图谱时，删掉安装目录下的 kg.db 后重新安装即可 （但这会丢弃你自己的编辑，请先导出备份）。

误删图谱怎么办：删除或替换 kg.db 后重启程序会恢复为出厂图谱。 若要保留自己的编辑，请先「导出图谱 CSV」备份。

五、配置文件（config.db 与 JSON）

配置存放于程序目录的 config.db（SQLite），包含三张表： kv（当前人物、语音开关、背景音乐、素材路径等标量项）、 frame_scale（每个人物的帧间隔与缩放）、 config_meta（记录播种来源等元信息）。

安装包内含一份出厂值，你的任何修改都会写回同一个文件。 为避免升级时覆盖你的设置，覆盖安装只在该文件不存在时才写入—— 想恢复出厂值，删掉 config.db 后重新安装即可。 若该文件意外缺失，程序会用内置默认值并按 assets.db 中已有的人物 自动登记帧率与缩放，功能完整可用。

导入 / 导出：一律用 JSON

  • 导出配置 JSON：把当前配置存到指定文件，可手工编辑后回导。
  • 导入配置 JSON：选择文件后会让你选择模式—— 覆盖整体替换当前设置（当前人物、语音开关、背景音乐都会随之切换）， 合并则只补充缺失的人物登记、保留现有设置。 导入报告会列出无法识别的键（会被忽略）。

自 v3.8 起配置只支持 JSON，不再提供 YAML 导出 / 导入。 若你手里还有旧版导出的 config.yaml，请先在文本编辑器里转成 JSON （顶层是一个对象，键名见下表）再导入；直接导入 .yaml 会得到明确的错误提示，而不会静默按 JSON 解析。

JSON 的顶层键名

键含义
audio是否播放人物语音（true / false）
bg_music正在播放的地区背景音乐，或 false
img_path帧图片目录名（出厂值 png）
music_path音频目录名（出厂值 music）
role当前伙伴名
frame_scale对象：键为人物名，值为 [帧间隔毫秒, 缩放比例]

容错：库文件缺失或内容损坏时会自动使用内置默认值，程序不会因此无法启动； 导入的配置若把当前人物指向了本地没有资源的人物，启动时会自动回退到第一个可用人物。 帧间隔与缩放在入库前会被夹到面板允许的范围（20~1000ms、0.1~3.0）。

恢复出厂值：面板不提供一键重置（避免误清空调好的缩放与帧率）。 如确需恢复出厂值，删除程序目录下的 config.db 后重新安装。

六、数据文件、备份与迁移

本程序的全部数据都在程序目录下，彼此独立、均为 SQLite：

文件内容丢了会怎样
assets.db素材：帧图片、人物语音、地区背景音乐 需要重新导入素材包（约 460MB）
kg.db知识图谱：实体、关系、属性 可重新安装恢复出厂图谱
config.db设置：当前人物、帧率、缩放、音频开关 回到默认设置，人物登记会自动补齐

换一台机器

把这三个文件拷到新机器的安装目录即可完整迁移。 也可以只带走「素材」页导出的素材包、配置 JSON、图谱 CSV，再在新机器上导入。

注意：不要在程序运行时手工替换这三个库——程序会持有 SQLite 连接， 直接覆盖可能造成数据损坏。请先从托盘「退出」结束程序再操作。

七、卸载与清理

安装目录默认为 %LOCALAPPDATA%\Programs\原神桌面伙伴 （即 C:\Users\你的用户名\AppData\Local\Programs\原神桌面伙伴）， 安装到用户目录因此无需管理员权限，程序也能正常读写自己的数据。

卸载会做什么

  • 先结束正在运行的程序：文件被占用是卸载失败最常见的原因， 卸载向导会先尝试关闭伙伴；
  • 删除整个安装目录，包括程序本体、依赖库、三个数据库、图标与本帮助文档；
  • 移除快捷方式：开始菜单、桌面（若勾选过）与开机自启（若勾选过）；
  • 清理运行期残留：缓存、日志、临时文件与构建期备份（*.bak-*）。

关于你的数据

卸载前会询问是否保留已导入的素材、知识图谱与设置：

  • 选择「否」：彻底删除三个数据库（约 460MB，不可恢复）；
  • 选择「是」：把它们复制到 %APPDATA%\原神桌面伙伴-备份\ 后再删除程序目录， 卸载完成后会提示备份位置；重装后把该目录下的三个 .db 拷回 安装目录的 _internal 子目录即可恢复。

无人值守的静默卸载（带 /SUPPRESSMSGBOXES）不会弹窗， 此时按保留处理——不会在你不知情的情况下销毁素材。

八、常见问题排查

现象原因与处理
任务栏没有伙伴的图标正常现象。伙伴只在系统托盘里， 托盘图标可能被折叠，点击任务栏托盘区（^）展开即可看到。
任务栏没有管理面板的图标面板尚未打开。托盘右键 →「管理面板」， 面板打开后会在任务栏出现独立图标。
找不到面板了点过「关闭面板」只是隐藏它。 托盘右键 →「管理面板」即可原样唤回（表单内容不会丢）。
全屏后看不到菜单栏按 Esc 退出全屏。
帮助页显示「未能载入帮助文件」安装目录里缺少 help.html。 重新安装即可；源码位于仓库的 res/help.html。
没有声音确认托盘「音乐」里地区背景音乐与人物语音都已开启（带「～」）； 也可在「音乐」页勾选「启用人物语音」。
没有问候语该人物可能没录这个时段的语音。程序会自动降级到该角色 已有的问候语；若一个都没有则跳过，不会出错。
人物不见了 / 帧播不出来多半是误删了 assets.db。 重新导入素材包即可；配置里该人物的登记会自动补齐。
双击安装包没有反应程序是单实例的。若已在运行，托盘里已有图标， 重复启动会直接退出。
升级后图谱编辑不见了旧版本安装器会用包内出厂图谱覆盖 kg.db。本版本已改为「仅当文件不存在时才写入」，升级不会再动你的数据； 若你是在旧版上丢过，可先用本版本重新安装并检查。
卸载后目录还在旧版本安装器存在这个缺陷（未删除非空目录）。 本版本已修复；若仍遇到，请手动删除安装目录，并检查是否有程序仍在运行。
